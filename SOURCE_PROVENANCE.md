# Kernel source provenance

Upstream: https://github.com/gta3xlwifi-dev/android_kernel_gta3xlwifi
Base commit: `00e4b9481434f9b0b644925a9bb2feaf3940219d` (the original checkout was shallow).
The complete base file tree is imported as a source snapshot, including COPYING.
Its original commit ID is recorded above; full upstream Git history is not imported.
This is Samsung's SM-T510 Exynos 4.4.302 kernel; consult per-file license notices.

The import removes 2282 tracked generated build files that `make
mrproper` removed in the actual build worktree. Host-generated DEFEX packer and
packed rules are kept at their upstream versions and regenerated by the build.
Seven intentional source changes are recorded separately: dtc host-tool symbol
compatibility, camera section lifetime, dedicated framework CPU PM QoS endpoints
and a separate GPU minimum-lock slot. Existing vendor controls and thermal limits
remain in place. The normal `exynos7885-gta3xlwifi_defconfig` is used.

Build scripts, GCC revision and validation notes:
https://github.com/oddhap/android_build_samsung_gta3xlwifi
The installed kernel was built with base HEAD plus uncommitted patches. A build
from committed sources may have different version text, timestamps and checksums.
The integration repository also preserves patches for that original base.
